# 09 — Інтеграція у Blueprint

*[🇬🇧 English](../en/09-Blueprint-Integration.md) | 🇺🇦 Українська*

## Компонент Fuzzy Logic

`UFuzzyLogicComponent` доступний у групі **Fuzzy Logic** та додається до будь-якого актора.

| Властивість | Значення |
|---|---|
| **System Asset** | Спільний `UFuzzySystemAsset`; має пріоритет |
| **Inline System** | Локальна система, коли асет не призначено |

## Передавання входів

| Вузол | Поведінка |
|---|---|
| **Set Input** | Записує одне значення; повертає `false`, якщо імені немає серед входів |
| **Set Inputs** | Записує `Map<Name,float>`; повертає кількість знайдених імен |
| **Get Input** | Повертає передане або типове значення |
| **Clear Inputs** | Забуває передані значення й повертає систему до `Default Value` |

Передані значення зберігаються між оцінюваннями. Оновлюйте лише те, що змінилося.

## Обчислення

| Вузол | Результат |
|---|---|
| **Evaluate** | Повний `FFuzzyInferenceResult` |
| **Evaluate Output** | Одне число за ім’ям виходу |
| **Evaluate Single Output** | Число єдиного виходу |
| **Get Last Result** | Попередній результат без нового обчислення |

Вузли Evaluate навмисно не є Pure: логічний висновок виконує роботу, і Pure-вузол міг би непомітно повторювати її для кожного читача піна.

## Типовий шаблон актора

```text
Event Tick або таймер
  → Set Input (Distance)
  → Set Input (Health)
  → Evaluate
  → Get Output (Aggression)
  → застосувати до швидкості, ваги переходу або вибору дії
```

Для великої кількості агентів не обов’язково рахувати кожен кадр. Оцінюйте за таймером, при суттєвій зміні входу або розподіляйте агентів між кадрами.

## Інспекція

| Вузол | Призначення |
|---|---|
| **Is System Valid** | Чи скомпільована система без помилок |
| **Validate System** | Повний список діагностик |
| **Get Input Names / Get Output Names** | Імена в порядку оголошення |
| **Get Last Output Surface** | Точна поверхня останнього обчислення |
| **Mark System Dirty** | Скинути кеш після ручної зміни структури системи |

## Статична бібліотека

`UFuzzyLogicStatics` зручна для одноразових операцій без компонента:

- `Evaluate Fuzzy System`;
- `Validate Fuzzy System`;
- `Parse Fuzzy Rule` та `Fuzzy Rule To String`;
- `Save/Load Fuzzy System To Json`;
- `Evaluate Fuzzy Set`;
- `Make Fuzzy Term Key`;
- `Describe Fuzzy Set`;
- `Fuzzy Diagnostic To String`.

Для багаторазового оцінювання використовуйте компонент: він кешує скомпільовану систему.

## Структура результату

Розгорніть `FFuzzyInferenceResult`, щоб отримати чіткі виходи, ступені входів, активації множин і правил та діагностику. Перевіряйте `bSuccess` або `Has Errors`, перш ніж застосовувати результат системи, яка може надходити з користувацьких даних.
