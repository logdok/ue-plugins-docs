# 08 — Редактор Data Asset

*[🇬🇧 English](../en/08-Asset-Editor.md) | 🇺🇦 Українська*

Створіть **Fuzzy System** через **Content Browser → Add → Miscellaneous → Data Asset** та відкрийте його подвійним кліком. Редактор має чотири вкладки; закриті вкладки відновлюються через меню **Window**.

## Toolbar

- **Save** зберігає пакет Unreal.
- **Load Preset** вибирає JSON із будь-якої папки. Документ спочатку парситься та повністю компілюється. Лише після успіху система замінює дані відкритого Data Asset.
- **Save To JSON** перевіряє поточну систему й експортує переносний пресет.

Успішний `Load Preset` підтримує Undo, позначає пакет як змінений і оновлює всі вкладки. Скасування файлового діалогу або помилка в JSON не змінює Data Asset.

## Details

Тут редагуються `Inputs`, `Outputs`, `Rules` і `Settings`. Заголовок кожної множини містить мініатюру функції належності. Розгорніть рядок, щоб змінити форму та параметри стандартними контролами Unreal.

Звичайні Save, Undo та Redo працюють для всіх авторських змін. Preview-значення з вкладки Inference не забруднюють Data Asset.

## Variables

Виберіть вхід або вихід, щоб побачити всі його множини на одному великому графіку. Легенда пов’язує множину з кольором. Для входів вертикальний маркер показує preview-значення, а горизонтальні маркери — ступені належності. Наведіть курсор на графік для читання координат.

## Inference

Основна область створена для одночасного спостереження:

- **Inputs — live controls** ліворуч: слайдери, числові поля та ступені належності;
- **Outputs — live results** праворуч: компактні картки з числом, агрегованою кривою та чітким маркером;
- **Rule firing strengths — details** унизу: окрема прокручувана панель правил.

Зміна входу негайно оновлює весь висновок. Виходи залишаються на екрані, навіть коли правил багато. Горизонтальний і вертикальний розділювачі можна перетягувати.

`Reset inputs` видаляє тимчасові перевизначення та повертає входи до поточних `Default Value`. Якщо діапазон звузився, preview автоматично затискається. Видалений вхід забувається.

## Compile Log

Показує діагностику компіляції та попередження останнього preview. Некоректне правило лишається видимим, має нульову активацію й позначається як пропущене. Значення, отримані із системи з помилками, є частковим preview і не повинні використовуватися як валідне рішення.

Про формат пресетів дивіться [11 — JSON-пресети](11-JSON-Presets.md).
