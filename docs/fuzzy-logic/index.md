**Fuzzy Logic 1.0**, for **Unreal Engine 5.8**. A complete Mamdani fuzzy inference plugin —
author fuzzy systems as reusable data assets or inline on an actor component, write rules in
readable `IF / THEN` text, and drive behavior from smooth graded decisions instead of brittle
thresholds. Nine built-in membership-function shapes plus custom C++ shapes, multiple outputs
per system, selectable T-norms, implication and aggregation, six defuzzification strategies,
JSON import/export, full diagnostics, and UMG helpers that plot exactly what the engine
decided.
