# Злиття у статичний меш

*[🇬🇧 English](../en/10-Merge-To-Static-Mesh.md) | 🇺🇦 Українська*

Інструмент **Merge to Static Mesh** запікає згенеровану геометрію кожного вибраного актора SplineCraft
Flow в окремий ассет `StaticMesh` і ставить на сцену відповідний `StaticMeshActor`. Він доступний лише в
редакторі, у категорії **SplineCraft Flow Tools** панелі **Details**, і не додає editor-only властивостей
до runtime-актора.

Це **рекомендований фінальний крок для великих конструкцій** — довгих доріг, огорож, трас і стін, — коли
їхні параметри вже не потрібно змінювати. Замість сотень компонентів отримуєте звичайну статичну
геометрію, яку зручніше перевіряти, переносити й оптимізувати засобами рушія.

## Робочий процес

1. **Повністю налаштуйте конструкцію**: форму сплайна, меші, матеріали й актори вздовж нього.
2. Виділіть на сцені один або кілька акторів SplineCraft Flow. Пакетна команда створить **по одному
   статичному мешу на кожен актор**, а не один спільний меш для всього виділення.
3. У **SplineCraft Flow Tools → Merge to Static Mesh** задайте **Destination Folder**. За замовчуванням
   це `/Game/Meshes`; вказуйте папку контенту повним package path, починаючи з `/Game`.
4. За потреби розгорніть **Advanced Merge Settings**. Це стандартні `FMeshMergingSettings` рушія:
   об'єднання й спрощення матеріалів, лайтмап-розгортка, **Pivot Point Type** тощо. Для більшості випадків
   достатньо значень за замовчуванням.
5. Перевірте рядок стану: він показує кількість придатних компонентів, папку результату та очікувані
   імена. Якщо шлях некоректний або зливати нічого, кнопка буде недоступною, а поруч з'явиться причина.
6. Натисніть **Create Static Mesh** або, для кількох акторів, **Create N Static Meshes**.
7. Після створення відкрийте отримані ассети й за потреби увімкніть **Nanite**, перевірте колізію та
   лайтмапи.

Без **Replace Source Actor** команда не потребує додаткового підтвердження: вихідні актори лишаються на
сцені. Під час великої пакетної операції редактор показує прогрес; помилка одного актора не зупиняє
обробку решти.

## Заміна вихідних акторів

Увімкніть **Replace Source Actor**, якщо після успішного створення меша вихідний актор SplineCraft Flow
потрібно видалити зі сцени. Перед запуском з'явиться підтвердження з кількістю ассетів і папкою
призначення, а панель окремо попереджає про різну поведінку Undo:

- створення нового `StaticMeshActor` і видалення вихідного актора скасовуються через **Undo**;
- створені в Content Browser ассети через Undo **не видаляються** — непотрібні результати видаліть вручну;
- усе пакетне створення й заміна акторів є одним кроком Undo.

Це навмисно **тимчасовий запобіжний перемикач**. Він не є властивістю актора, не зберігається в рівні чи
Blueprint і не запам'ятовується як користувацьке налаштування. Після виконання команди значення
скидається; для наступної заміни його треба ввімкнути знову.

## Результат пакетної операції

- Для кожного придатного вихідного актора створюється окремий ассет
  `<Destination Folder>/SM_<ім'я актора>` і окремий `StaticMeshActor` у тому самому рівні.
- Якщо ім'я вже зайняте, рушій додає номер (`SM_<ім'я актора>_1` тощо). Наявні ассети ніколи не
  перезаписуються.
- Успішно створені `StaticMeshActor` стають новим виділенням, а Content Browser переходить до створених
  ассетів.
- Актор без придатних статичних мешів пропускається; пакет продовжується, підсумок показує кількість
  успішних і пропущених акторів, а подробиці потрапляють до Output Log (`LogSplineCraftFlow`).
- Якщо не вдалося створити жодного меша, транзакція акторів скасовується й панель показує помилку.

## Що потрапляє в злиття

- Усі валідні компоненти зі статичним мешем на самому акторі: інстанси режиму **Line**, сплайн-меші
  режиму **Curve** та компоненти, додані вами в Blueprint-нащадку.
- Статичні меш-компоненти дочірніх акторів, розставлених уздовж сплайна (**Actors**).

Логіка дочірніх акторів, світло, Niagara, аудіо й інші нестатичні компоненти не зливаються.

## Налаштування й збереження

| Параметр | За замовчуванням | Чи зберігається | Призначення |
|---|---|---|---|
| **Destination Folder** | `/Game/Meshes` | так, окремо для користувача й проєкту | папка Content Browser для нових ассетів; повний package path без імені ассета. |
| **Advanced Merge Settings** | стандартні значення рушія | так, окремо для користувача й проєкту | налаштування `FMeshMergingSettings`, які застосовуються до кожного актора в пакеті. |
| **Replace Source Actor** | вимкнено | ні | після успішного злиття видалити відповідний вихідний актор зі сцени. |

Перші два параметри переживають перезапуск редактора, але не серіалізуються в `ASplineCraftFlowActor` і
не змінюють рівень чи Blueprint. Це персональні editor-настройки поточного проєкту. Небезпечніший вибір
**Replace Source Actor** навмисно не зберігається.

## Обмеження

- **Злитий меш не пов'язаний із вихідним актором.** Щоб змінити конструкцію, відредагуйте вихідний актор
  (або поверніть його через Undo після заміни) і створіть новий меш.
- **Один великий меш відсікається цілком.** Дуже довгі конструкції краще розділити на кілька акторів і
  запекти пакетно: результат усе одно буде окремим для кожного.
- Налаштування merge можуть суттєво змінити матеріали, UV, pivot і колізію. Важливий фінальний результат
  перевірте в Static Mesh Editor.
