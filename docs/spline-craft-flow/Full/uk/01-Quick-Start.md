# Швидкий старт

*[🇬🇧 English](../en/01-Quick-Start.md) | 🇺🇦 Українська*

Цей розділ проведе шлях від встановлення плагіна до першої згенерованої конструкції на сцені.

## Встановлення

**З Fab / Epic Games Launcher.** Знайдіть SplineCraft Flow у бібліотеці, натисніть *Install to Engine* і
виберіть версію рушія 5.8. Плагін встановиться в теку рушія.

**Вручну.** Скопіюйте теку `SplineCraftFlow` у `<Проєкт>/Plugins/` (створіть `Plugins`, якщо її нема).
Так плагін живе всередині проєкту й їде разом із ним у систему контролю версій.

## Увімкнення плагіна

1. **Edit → Plugins**.
2. У пошуку введіть `SplineCraft Flow`.
3. Поставте галку **Enabled**.
4. Перезапустіть редактор, коли він запропонує.

Щоб бачити контент плагіна в Content Browser, увімкніть *Settings → Show Plugin Content*.

## Перша конструкція за 5 кроків

1. **Розмістіть актор.** Перетягніть на сцену `BP_SplineCraftFlowActor`
   (*Plugins → SplineCraft Flow Content → Blueprint*) або клас **Spline Craft Flow Actor** з панелі
   *Place Actors*. Актор має корінь `DefaultSceneRoot` і компонент `SplineComponent` з двома точками.
2. **Задайте форму сплайна.** Виділіть актор і рухайте точки сплайна у в'юпорті (Alt-перетягування
   додає точку). Для готової форми відкрийте editor mode **Spline Geometry**, додайте, наприклад,
   модифікатор **Ellipse**, перегляньте preview і натисніть **Apply**. Детально —
   [Сплайн і стратегії розміщення точок](02-Spline-And-Placement-Strategies.md).
3. **Додайте меш.** У масиві **Static Meshes** натисніть **+**, розгорніть запис і призначте
   **Static Mesh**. Меші розкладуться вздовж усього сплайна.
4. **Виберіть режим.** Поле **Mode** актора: `Line` — прямі інстанси (найшвидше), `Curve` — меші
   гнуться вздовж кривої, `Use Concrete Mode in Mesh Configuration` — кожен запис вирішує сам через своє
   поле **Mode**. Детально — [Режими Line та Curve](04-Line-vs-Curve-Mode.md).
5. **Налаштуйте вигляд.** **Spacing**, **Additional Offset**, **Additional Scale**, матеріали,
   рандомізація, актори вздовж сплайна — див. розділи [03](03-Static-Meshes.md)–[08](08-Actors-Along-Spline.md).

## Що варто знати одразу

- **Геометрія перебудовується сама** після кожної зміни властивості в редакторі (`OnConstruction`) і на
  старті гри (`BeginPlay`). Нічого «застосовувати» не треба.
- **Spline Geometry працює стеком модифікаторів.** Порядок кроків впливає на результат; preview не
  змінює справжній сплайн до натискання **Apply**.
- **Замкнений сплайн** вмикається галкою **Loop** на акторі (а не на компоненті сплайна — актор
  перезаписує цей прапорець при кожній перебудові).
- **Поворот і масштаб актора** не змінюють розкладку відносно актора — конструкція повертається і
  масштабується як ціле. Детально — [розділ 09](09-Transform-Mobility-And-Blueprint.md).
- Для великих фінальних конструкцій — [Merge to Static Mesh](10-Merge-To-Static-Mesh.md).
- Для повторного використання налаштованого стилю — [SplineCraft Flow Preset](13-Presets.md).
