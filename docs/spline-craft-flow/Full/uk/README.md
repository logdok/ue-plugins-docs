# Посібник користувача SplineCraft Flow

*[🇬🇧 English](../en/README.md) | 🇺🇦 Українська*

SplineCraft Flow — плагін для швидкої побудови конструкцій уздовж сплайна зі статичних мешів і акторів:
дороги, рейки, труби, огорожі, бордюри, мости, треки, ряди колон, ліхтарів чи дерев. Уся конфігурація
виконується на одному акторі `ASplineCraftFlowActor` через панель **Details** (категорія
**SplineCraft Flow**), а геометрія перебудовується автоматично після кожної зміни властивості.

> **SplineCraft Flow 7.0.0**, для Unreal Engine 5.8. Що нового в цьому випуску — [Примітки до випуску](Release-Notes.md).

## Швидкий старт

1. **Встановіть плагін** — з Fab / Epic Games Launcher (*Install to Engine*) або скопіювавши теку
   `SplineCraftFlow` у `<Проєкт>/Plugins/`.
2. **Увімкніть його** — *Edit → Plugins → SplineCraft Flow → Enabled*, перезапустіть редактор.
3. **Розмістіть актор** — `BP_SplineCraftFlowActor` з контенту плагіна або клас **Spline Craft Flow Actor**
   з панелі *Place Actors*.
4. **Задайте форму сплайна** — рухайте точки у в'юпорті або застосуйте стек модифікаторів у
   **Spline Geometry Edit Mode** (прямокутник, еліпс, спіраль, дорога, петлі тощо).
5. **Додайте меш** — у масиві **Static Meshes** створіть запис і призначте **Static Mesh**. Конструкція
   збереться одразу.

Детальніше — [01. Швидкий старт](01-Quick-Start.md).

## Словник

- **Запис меша** (`FSPMeshConfiguration`) — один «шар» однакових мешів уздовж усього сплайна зі своїми
  налаштуваннями відступів, масштабу, матеріалів і рандомізації. Записів може бути скільки завгодно.
- **Сегмент** — один екземпляр меша в межах запису: у режимі **Line** це інстанс, у режимі **Curve** —
  окремий зігнутий `SplineMeshComponent`.
- **Режим Line / Curve** — спосіб розміщення: прямі інстанси проти мешів, що гнуться вздовж кривої.
- **Запис актора** (`FSPSplineActorConfig`) — актори заданого класу, розставлені вздовж сплайна з кроком.
- **Діапазон відстані** (`FSPDistanceRange`) — ділянка сплайна у відсотках чи метрах; використовується для
  прихованих ділянок і матеріалів.
- **Модифікатор геометрії** — крок у стеку **Spline Geometry Edit Mode**, що будує або змінює точки сплайна.
- **Пресет** (`USplineCraftFlowPreset`) — повторно використовуваний стиль генерації без форми сплайна та **Loop**.
