# Статичні меші

*[🇬🇧 English](../en/03-Static-Meshes.md) | 🇺🇦 Українська*

Масив **Static Meshes** на акторі — це список «шарів» мешів. Кожен запис (`FSPMeshConfiguration`)
розкладає один статичний меш уздовж усього сплайна: дорожнє полотно, бордюр ліворуч, бордюр праворуч,
рейку, трубу. Записи незалежні: у кожного свій крок, відступи, матеріали, рандомізація й режим.

## Як меш заповнює сплайн

- **Довжина меша** — розмір його bounding box уздовж осі X. Меш має бути змодельований уздовж осі X, з
  опорною точкою (pivot) по центру.
- **Крок** уздовж сплайна = довжина меша + **Spacing**. У режимі **Curve** довжина множиться на
  **Additional Scale X**.
- Кількість сегментів = довжина сплайна / крок (з округленням униз) + 1. Останній сегмент може виходити за
  кінець сплайна — тоді він притискається до кінця.
- Відстань уздовж сплайна вимірюється в локальних одиницях актора (див.
  [розділ 09](09-Transform-Mobility-And-Blueprint.md)).

## Параметри запису меша

| Параметр | Призначення |
|---|---|
| **Design Notes** | вільна нотатка для дизайнера. |
| **Static Mesh** | меш, який розкладається вздовж сплайна. Запис без меша ігнорується. |
| **Mode** | `Line` або `Curve` для цього запису. Діє лише коли **Mode** актора = `Use Concrete Mode in Mesh Configuration`. Див. [розділ 04](04-Line-vs-Curve-Mode.md). |
| **Spacing** | проміжок між сусідніми мешами, см. Від'ємне значення — перекриття. |
| **Vertical Align** | тримати меш вертикально (без нахилу й крену сплайна). Лише режим **Line**. |
| **Additional Offset** | зсув, см: X — уздовж сплайна, Y — праворуч, Z — угору. |
| **Additional Scale** | додатковий масштаб. У режимі **Curve** X також видовжує меш уздовж сплайна (і крок). |
| **Additional Rotation** | додатковий поворот. **Line** — усі осі; **Curve** — лише Roll (крен навколо сплайна). |
| **Twist Amount** | закрутка: кількість повних обертів навколо сплайна на всю його довжину. Лише режим **Curve**. |
| **Receive Decals** | чи отримують меші декалі. |
| **Materials** / **Apply Every Index** | заміна матеріалів — див. [Матеріали](06-Materials.md). |
| **Materials Distance Ranges** | матеріали на ділянках сплайна — див. [Матеріали](06-Materials.md). |
| **Hidden Ranges** | ділянки, де меші не створюються — див. [розділ 05](05-Distance-Ranges.md). |
| **Slot Materials** | матеріал для конкретного слота на ділянках — див. [Матеріали](06-Materials.md). |
| **Collision Enabled** | режим колізії мешів (нижче). |
| **Randomization Settings** / **Random Seed** | розкид масштабу, зсуву й повороту — див. [розділ 07](07-Randomization.md). |

## Відступи

- **Line.** Зсув X пересуває інстанс уздовж сплайна (на відстань), Y і Z — від точки на сплайні вздовж
  його правого та верхнього напрямків. Зсув Z додатково множиться на масштаб точки сплайна (Z).
- **Curve.** Зсув X зсуває весь сегмент уздовж кривої (кінці переобчислюються на кривій, а не
  екстраполюються), Y і Z — у площині, перпендикулярній до кривої.

## Колізія

| Режим | Line (інстанси) | Curve (сплайн-меші) |
|---|---|---|
| `No Collision` | колізія вимкнена, усі канали — Ignore. | усі канали — Ignore. |
| `Query Only` / `Physics Only` / `Query And Physics` | профіль колізії береться з меша, тип — з параметра. | усі канали — Block, тип — з параметра. |

Колізія статичних мешів залежить від простої колізії, налаштованої в самому ассеті меша.

## Порядок побудови

1. Записи мешів обробляються згори донизу, сегменти — від початку сплайна.
2. У режимі **Line** інстанси з однаковими (запис, матеріали) збираються в один
   `InstancedStaticMeshComponent`.
3. Згенеровані компоненти прикріплюються до `SplineComponent` і перестворюються при кожній перебудові.
   Компоненти, які ви додали самі (у Blueprint-нащадку або на екземплярі актора), не зачіпаються.
