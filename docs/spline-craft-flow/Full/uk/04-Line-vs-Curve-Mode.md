# Режими Line та Curve

*[🇬🇧 English](../en/04-Line-vs-Curve-Mode.md) | 🇺🇦 Українська*

Режим визначає, у які компоненти рушія потрапляють згенеровані меші і чи гнуться вони вздовж кривої.

## Глобальний режим актора (`Mode`, `ESPUsingSpawnMode`)

| Значення | Дія |
|---|---|
| **Use Concrete Mode in Mesh Configuration** | кожен запис мешів вирішує сам за власним полем **Mode** (значення за замовчуванням). |
| **Line** | усі записи — прямі інстанси в `InstancedStaticMeshComponent`. Найкраща продуктивність. |
| **Curve** | усі записи — окремі `SplineMeshComponent`, що гнуться вздовж кривої. |
| **Visible Only Spline** | нічого не створюється — лише сплайн. Зручно для налагодження форми; актори вздовж сплайна теж не з'являються. |

## Режим запису (`Mode`, `ESPSpawnMode`)

У кожного запису в **Static Meshes** є власне поле **Mode**: `Line` або `Curve` (за замовчуванням
`Curve`). Воно діє **лише** коли глобальний режим актора = `Use Concrete Mode in Mesh Configuration`.
Так на одній конструкції можна тримати прямі плити в Line, а гнучку трубу — у Curve.

## Line

- Кожен сегмент — інстанс меша в точці сплайна, повернутий за напрямком сплайна.
- Інстанси одного запису з однаковими матеріалами збираються в один компонент і додаються одним пакетом —
  сотні мешів коштують кілька draw calls.
- Меш **не гнеться**: на кривих ділянках це прямі шматки, повернуті вздовж кривої.
- Доступні **Vertical Align**, повний **Additional Rotation**, **Flip X / Flip Y**.
- Опорна точка інстанса — центр сегмента (початок сегмента + половина довжини меша + зсув X).

## Curve

- Кожен сегмент — окремий `SplineMeshComponent`, що деформує меш між початком і кінцем сегмента.
- Меш повторює вигин кривої — підходить для труб, рейок, поручнів, доріг на поворотах.
- **Additional Scale X** видовжує меш уздовж сплайна; Y і Z масштабують переріз, зокрема з урахуванням
  масштабу точок сплайна на початку й кінці сегмента.
- **Additional Rotation** — лише Roll; **Twist Amount** закручує меш навколо кривої.
- Кількість компонентів росте швидко: 200 сегментів = 200 компонентів.
- Для рівного результату меш має бути достатньо деталізований уздовж осі X (кілька петель ребер), інакше
  він гнеться «ламано».

## Що обирати

| Ситуація | Режим |
|---|---|
| Прямі елементи, огорожі, стовпи, шпали, більшість сцен | **Line** |
| Меш має гнутися вздовж кривої (труби, рейки, дорожнє полотно) | **Curve** |
| Змішана конструкція | **Use Concrete Mode in Mesh Configuration** + **Mode** у записах |
| Велика фінальна конструкція | будь-який режим + [Merge to Static Mesh](10-Merge-To-Static-Mesh.md) + Nanite |
