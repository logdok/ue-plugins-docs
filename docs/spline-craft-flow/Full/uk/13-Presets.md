# Пресети стилю генерації

*[🇬🇧 English](../en/13-Presets.md) | 🇺🇦 Українська*

`USplineCraftFlowPreset` — Data Asset із повторно використовуваним стилем генерації SplineCraft Flow.
Один пресет можна застосувати до багатьох акторів із різною формою сплайна: наприклад, зберегти один
набір секцій огорожі, опор і матеріалів, а потім швидко призначати його різним маршрутам.

Усі команди розташовано в **Details → SplineCraft Flow Tools → Preset**.

## Що входить до пресета

| Дані | Призначення |
|---|---|
| **Mode** | глобальний режим розміщення елементів. |
| **Static Meshes** | усі записи `FSPMeshConfiguration`, включно з матеріалами, діапазонами, відступами й рандомізацією. |
| **Actors** | усі записи `FSPSplineActorConfig`. |
| **Mobility** | мобільність актора, сплайна та згенерованих компонентів. |
| **Scale Structure With Actor** | поведінка відстаней при масштабуванні актора. |
| **Stable Curve Orientation** | стабільна орієнтація Curve-мешів. |
| **Description** | нотатка всередині ассета; команда **Save to Preset** її не перезаписує. |

Пресет навмисно **не змінює** форму й трансформацію сплайна, **Loop**, інструменти геометрії,
тимчасовий reference spline, папки експорту та merge settings. Це дані конкретного актора або
персональні editor-настройки, а не частина стилю.

## Створення з налаштованого актора

1. Налаштуйте актор так, як має виглядати повторно використовуваний стиль.
2. У **Preset Folder** виберіть папку Content Browser. Типове значення —
   `/Game/SplineCraftFlow/Presets`; воно запам'ятовується окремо для користувача й проєкту.
3. Натисніть **Create Preset from Actor**.

Редактор створить унікальний ассет `P_<ім'я актора>`, скопіює в нього стиль, призначить новий пресет
акторові й покаже його в Content Browser. Наявні ассети не перезаписуються: до зайнятого імені додається
номер. Для кількох виділених акторів створюється по одному пресету на кожен.

Альтернативний стандартний шлях: **Content Browser → правий клік → Miscellaneous → Data Asset →
SplineCraft Flow Preset**. Після цього призначте ассет у полі **Preset**.

## Застосування й оновлення

- **Apply Preset** копіює стиль призначеного пресета на актор і відразу перебудовує конструкцію. Вибір
  ассета в полі **Preset** сам по собі нічого не застосовує. Для кількох акторів команда використовує
  власний призначений пресет кожного актора й виконується одним кроком **Undo**.
- **Save to Preset** перезаписує спільний ассет поточними налаштуваннями одного виділеного актора.
  Перед записом редактор показує ім'я ассета й просить підтвердження. Опис пресета, сплайн і **Loop** не
  змінюються. Після команди ассет позначено як змінений — збережіть його звичайною командою редактора.

Якщо кілька акторів посилаються на один ассет, **Save to Preset** оновлює сам ассет, але інші актори не
перебудовуються автоматично. Виділіть їх і натисніть **Apply Preset**, коли будете готові прийняти нову
версію стилю.

## Runtime і Blueprint

Клас пресета та поле **Preset** належать Core-модулю й доступні в runtime. Blueprint-функція
**Apply Preset** приймає `SplineCraft Flow Preset`, копіює стиль і перебудовує актор; повертає `false`
для невалідного ассета. Створення ассетів, перезапис Content Browser і редакторські діалоги залишаються
в модулі `SplineCraftFlowEditor` і не потрапляють до packaged game.
