# Рандомізація та Random Seed

*[🇬🇧 English](../en/07-Randomization.md) | 🇺🇦 Українська*

**Randomization Settings** запису меша додають керований розкид масштабу, зсуву й повороту між
сегментами. Кожен параметр задається діапазоном **From**..**To**; значення береться рівномірно з цього
діапазону. Кожна група вмикається своєю галкою.

## Масштаб

| Параметр | Призначення |
|---|---|
| **Use Scale Randomization** | увімкнути розкид масштабу. |
| **Uniform Scale** | однаковий множник по всіх осях — діапазон **XYZ Scale**. Вимкнено — окремі **X Scale**, **Y Scale**, **Z Scale**. |
| **Use Same Scale For Start And End** | у режимі **Curve**: однаковий множник на початку й кінці сегмента. Вимкнено — кінець отримує власне випадкове значення, і меш плавно змінює товщину. |
| **Match End And Start Scale** | у режимі **Curve**: початок кожного сегмента бере масштаб кінця попереднього — переходи між сегментами без сходинок. |

Випадковий множник помножується на масштаб точки сплайна й **Additional Scale**. Значення масштабу не
можуть бути від'ємними.

## Зсув

| Параметр | Призначення |
|---|---|
| **Use Offset Randomization** | увімкнути розкид зсуву. |
| **X Offset** / **Y Offset** / **Z Offset** | діапазони зсуву, см: X — уздовж сплайна, Y — убік, Z — угору. Додаються до **Additional Offset**. |

У режимі **Line** випадковий зсув X — це зсув уздовж напрямку інстанса по прямій; у режимі **Curve** —
зсув сегмента вздовж кривої.

## Поворот

| Параметр | Призначення |
|---|---|
| **Use Rotation Randomization** | увімкнути розкид повороту. |
| **Roll** / **Pitch** / **Yaw** | діапазони кутів, градуси. |
| **Flip X** / **Flip Y** | лише **Line**: випадковий поворот на 0° або 180° навколо вертикальної осі; обидві галки — на випадковий кут, кратний 90°. Працює, лише коли ввімкнено **Use Rotation Randomization**. |

> У режимі **Curve** **Roll** крутить меш навколо кривої, а **Pitch** і **Yaw** нахиляють дотичні
> сегмента; **Flip** ефекту не має.

## Random Seed

**Random Seed** запису (за замовчуванням 0) робить розкид відтворюваним: з тим самим сидом конструкція
збирається ідентично при кожній перебудові, на будь-якому комп'ютері та в грі.

- Кожен сегмент отримує власну послідовність випадкових чисел, що залежить від сиду та номера сегмента.
  Тому видовження сплайна додає нові сегменти в кінці, не змінюючи випадкових значень уже наявних.
- Щоб отримати інший варіант розкиду, змініть **Random Seed**.
- Два записи з однаковим сидом і однаковими налаштуваннями отримають однаковий розкид.

> **Зауваження.** Увімкнення чи вимкнення групи рандомізації змінює порядок випадкових значень усередині
> сегмента, тому при тому самому сиді вигляд може змінитися — це властивість самого підходу.

## Коли відбувається перерахунок

- При кожній зміні властивості в редакторі.
- На старті гри (`BeginPlay`).
- У runtime — при виклику **Build Elements Along Spline** (див. [розділ 09](09-Transform-Mobility-And-Blueprint.md)).
