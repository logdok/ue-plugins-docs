# UE Plugins Documentation

Documentation for Unreal Engine plugins developed by [logdok](https://github.com/logdok). The source code for each plugin lives in its own private repository; this site collects the public-facing documentation for all of them in one place.

## Plugins

- **[QuestSystem](quest-system/index.md)** — event-driven, data-driven quest system with first-class multiplayer support and zero-config integration. Available in a Full edition and an evaluation Demo edition, both documented in English and Ukrainian.
- **[S3 Compatible Storage](s3-compatible-storage/index.md)** — object storage on any S3-compatible provider ([Amazon S3](https://aws.amazon.com/s3/), [Cloudflare R2](https://www.cloudflare.com/developer-platform/products/r2/), [Backblaze B2](https://www.backblaze.com/cloud-storage), [Google Cloud Storage](https://cloud.google.com/storage), [MinIO](https://min.io/) and more), from Blueprint or C++. Verified against six real providers. Documented in Ukrainian; English in preparation.
