# Режими Line та Curve

*[🇬🇧 English](../en/09-Line-vs-Curve-Mode.md) | 🇺🇦 Українська*

Режим визначає, у які компоненти рушія потрапляють згенеровані меші.

## Глобальний режим актора (`Mode`, `ESplineCraftUseMode`)

| Значення | Дія |
|---|---|
| **Concrete** | кожен елемент вирішує сам за власним параметром `Mode`. |
| **Line** | усі меші йдуть в `InstancedStaticMeshComponent`. Найкраща продуктивність. |
| **Curve** | меші секцій і труб ідуть у `SplineMeshComponent` (згинаються вздовж кривої); стовпи та вузли — все одно в ISM. |

## Режим елемента (`ESplineCraftMode`)

У кожної `Main Static Mesh Configuration` секції або труби є власний **Mode**: `Line` або
`Curve`. Він застосовується **лише** коли глобальний **Mode** актора = `Concrete`. Так можна
на одній структурі тримати прямі панелі в Line, а гнучкий поручень — у Curve.

## Line

- Меші складаються в `InstancedStaticMeshComponent`, по одному компоненту на **унікальну пару
  «меш + матеріали»**.
- Дешево: сотні стовпів — це кілька draw calls.
- Проміжок між точками меш заповнює **розтягуванням уздовж прямої** (хорди) між сусідніми
  точками. На кривому сплайні проліт лишається прямим відрізком.
- Уся структура лишається редагованою.

## Curve

- Кожен елемент кожного прольоту стає окремим `SplineMeshComponent`, що **згинається вздовж
  кривої**.
- Кількість компонентів росте швидко: друга секція на сплайні з 50 точок — це ще ~50
  компонентів. Слідкуйте за секцією **Stats** у Details.
- Потрібно там, де меш справді має повторювати вигин: гнуті поручні, труби, кільця.

## Що обирати

| Ситуація | Режим |
|---|---|
| Прямі паркани, стіни, щити, більшість сцен | **Line** |
| Меш має гнутися вздовж кривої | **Curve** |
| Змішана структура | **Concrete** + `Mode` на елементах |
| Велика фінальна структура | будь-який режим + [Merge to Static Mesh](11-Merge-To-Static-Mesh.md) + Nanite |
