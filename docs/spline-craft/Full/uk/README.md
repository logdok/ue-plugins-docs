# Посібник користувача SplineCraft

*[🇬🇧 English](../en/README.md) | 🇺🇦 Українська*

SplineCraft — інструмент для швидкої генерації структур (композицій зі `StaticMesh` та `Actor`)
уздовж сплайна: огорожі, поручні, балюстради, колонади, аркади, барикади, мости, дороги тощо.
Уся конфігурація виконується на одному акторі `ASplineCraftActor` через панель **Details**
(категорія **SplineCraft Configuration**), а геометрія перебудовується автоматично після кожної
зміни властивості.

> Для **Unreal Engine 5.8**. Що нового в цьому випуску — [Примітки до випуску](Release-Notes.md).

## Швидкий старт

1. **Встановіть плагін** — з Fab / Epic Games Launcher (*Install to Engine*) або скопіювавши
   теку `SplineCraft` у `<Проєкт>/Plugins/`.
2. **Увімкніть його** — *Edit → Plugins → SplineCraft → Enabled*, перезапустіть редактор.
3. **Киньте на сцену** актор **SplineCraft Actor** (браузер *Place Actors*).
4. **Задайте форму сплайна** — рухайте точки у в'юпортi або відкрийте
   **SplineCraft Configuration → Utils → Alignment Spline Points**, виберіть **Tool**
   (наприклад, `Rectangle` чи `Ellipse`) і задайте параметри.
5. **Призначте меші** — у секції **POSTS** додайте запис і призначте **Static Mesh** стовпа,
   у секції **SECTIONS** — **Static Mesh** панелі. Геометрія збереться одразу.

Детальніше — [01. Швидкий старт](01-Quick-Start.md). Готові стилі лежать у `Content/Samples`
(`DA_Preset_IronFence`); призначте пресет у поле **Preset** і натисніть **Apply Preset**.

## Словник елементів

- **Posts** — меш у кожній точці сплайна (стовп, балясина).
- **Sections** / **Tubes** — меш у проміжку між сусідніми точками (панель, поручень, рейка).
- **Knobs** — декоративні меші на стовпі або елементі у заданій позиції.
- **Free Knobs** — вузли в локальних координатах актора, не прив'язані до точок сплайна.
- **Polygons** — заповнені форми, що генеруються процедурним мешем.

## Перейменування плагіна

Раніше плагін називався **SplineCraft PRO**. Тепер він називається просто **SplineCraft**.
Перейменування **не впливає на зворотну сумісність**: назва модуля (`SplineCraft`), точка
монтування контенту (`/SplineCraft/...`), шляхи до класів (`/Script/SplineCraft.*`) і розкладка
властивостей та структур (`FSC*`) не змінилися. Наявні рівні, Blueprint-нащадки
`ASplineCraftActor` та посилання на ассети продовжують працювати без змін. Змінилися лише назва
теки плагіна та відображувана назва (`FriendlyName`). Ассет `BP_SplineCraft_PRO` навмисно **не**
перейменовано, щоб не зламати посилання у проєктах.
