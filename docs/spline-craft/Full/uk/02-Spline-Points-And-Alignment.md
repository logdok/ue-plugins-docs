# Точки сплайна та вирівнювання

*[🇬🇧 English](../en/02-Spline-Points-And-Alignment.md) | 🇺🇦 Українська*

Форму структури задає сплайн у корені актора. Точки можна редагувати вручну або розкласти
одним із інструментів (`SplinePointsAlignTool`).

## Ручне редагування

Виділіть актор — компонент сплайна стає активним у в'юпортi. Далі як зі звичайним
`USplineComponent`:

- **Alt-перетягування** точки додає нову; **Delete** видаляє виділену.
- Перетягуйте маркери дотичних, щоб змінити кривизну.
- У панелі Details точки сплайна є **Spline Point Type** для кожної точки: `Curve` (гладко),
  `Linear` (злам), `Constant`.

Якщо вибрано інструмент розкладки, він **не** затирає ручні правки: інструмент спрацьовує
лише коли змінюються його власні налаштування (див. «Нелипкі інструменти» нижче).

## Загальні параметри

| Параметр | Призначення |
|---|---|
| **Mode** (`ESplineCraftUseMode`) | `Concrete` / `Line` / `Curve` — глобальна стратегія розміщення. Див. [Режими Line та Curve](09-Line-vs-Curve-Mode.md). |
| **Visible Last Point Elements** | показувати стовпи та вузли в останній точці незамкненого сплайна (`bCloseSection`). |
| **Spline Close Loop** | замкнути сплайн у петлю. Недоступно для інструментів Line, Sinusoid, Arc, Spiral, Zigzag, Catenary. |
| **Num Spline Points** | скільки точок будує обраний інструмент розкладки (для інструментів, що будують форму з нуля). |
| **Design Notes** | вільна текстова нотатка на акторі. |

## Панель Utils

У випадному списку **Tool** видно тільки опції обраного інструмента; решта прихована. Кожен
пункт списку має підказку. Кнопка **Apply Point Layout** розкладає точки заново вручну — коли
це справді потрібно.

## Інструменти вирівнювання (Tool)

### Manual
Точки розставляються вручну. Жоден інструмент сплайн не чіпає.

### Line
Пряма низка рівномірно розставлених точок. **Step** — крок (м). Потрібно ≥ 2 точки.

### Rectangle
Замкнений прямокутник. **Clockwise**, **Rectangle Length (X)** / **Rectangle Width (Y)** (м),
**Bevel** — фаска кутів (м). Точка завжди ставиться на кожен кут (4, або 8 з фаскою); решта
розподіляються вздовж ребер пропорційно їхній довжині, тож відстань між точками максимально
рівномірна по всьому периметру навіть для неквадратного прямокутника. Потрібно ≥ 4 точки
(≥ 8 з фаскою — кількість піднімається до цього, якщо менша).

### Ellipse
Замкнений еліпс, рівномірно поділений на задану кількість точок. **Clockwise**,
**Diameter X** / **Diameter Y** (м). Потрібно ≥ 3 точки.

### Sinusoid
Синусоїда вздовж осі X. **Amplituda** (м), **Frequency**. Необов'язковий випадковий розкид
амплітуди (**Random Settings**), який можна вимкнути прапорцем **Ignore Random Settings**.

### Uniform
Перерозподіляє **вже наявні** точки рівномірно вздовж сплайна. **Use Every Nodal Point** —
через скільки вузлів вирівнювати; **Vertical Points** — вирівняти точки вертикально.

### Bind To Surface
Опускає **вже наявні** точки на поверхню під ними трасуванням строго вниз.
**Vertical Points** — поставити точки вертикально; **Additional Vertical Shift** (см);
**Trace Distance Above** / **Trace Distance Below** — на яку відстань угору й униз шукати
поверхню (см). Тримайте «вгору» невеликим, щоб не зачепити міст або дах над точкою.

### Arc
Частина еліпса. **Diameter X** / **Diameter Y** (м), **Start Angle** — кут початку (0 — вздовж
+X), **Sweep Angle** — розмах (90 — чверть, 180 — половина), **Clockwise**.
**Even Spacing** (типово увімкнено) — рівні кроки по довжині кривої; вимкніть, щоб крокувати
по куту.

### Regular Polygon
Замкнений правильний многокутник із рівними сторонами. **Diameter** (м), **Start Angle** —
повертає фігуру на місці (наприклад, поставити шестикутник на сторону, а не на кут),
**Sharp Corners** — тримати сторони прямими (вимкнено — фігура округлюється), **Clockwise**.
Потрібно ≥ 3 точки.

### Spiral
Спіраль, а з висотою — гвинтова лінія. **Start Diameter** / **End Diameter** (м) —
діаметр змінюється від початку до кінця; **Turns** — кількість обертів (дробова);
**Height** — загальний підйом (м; 0 — плоска спіраль); **Clockwise**; **Even Spacing**.
Підходить для спіральних сходів, пандусів, колодязів.

### Zigzag
Точки по черзі відходять убік від осі X. **Step** — крок по X (м), **Amplitude** — розмах
убік (м), **Vertical** — хитати вгору-вниз замість убік (пилкоподібний профіль),
**Sharp Corners** — тримати кути гострими (вимкнено — виходить хвиля).

### Catenary
Крива, яку приймає вільно висяча цепь. **Span** — відстань між кінцями (м; кінці на рівні
актора), **Sag** — на скільки середина опускається нижче кінців (м). **Від'ємне значення
перевертає криву вгору** — виходить арка (форма арочного моста). **Even Spacing** —
рівні кроки по довжині кривої (однакові ланки цепу); вимкніть, щоб крокувати по X.
Для цепних огорож між тумбами, канатних бар'єрів, гірлянд, дротів — і, з від'ємним
значенням, арочних мостів та склепінь.

### Follow Spline
Копіює точки сплайна з іншого актора — дороги, річки, краю обриву, готового шляху — щоб
структура йшла рівно вздовж. **Reference Actor** — актор із компонентом сплайна (сам себе
референсом бути не може); **Lateral Offset** — увести структуру на задану відстань убік (м;
додатне — праворуч уздовж референса); **Reverse Direction** — обхід від кінця до початку;
**Match Reference Height** — брати висоту з референса (їхати по його підйомах) чи тримати все
на рівні актора. Тип кожної точки (гладка/кутова) і замкненість переносяться з референса,
тому гострі перехрестя лишаються гострими.

## Про Even Spacing

Рівний крок за **кутом** — це не рівний крок за **відстанню**, щойно діаметри дуги різні або
у спіралі росте радіус: без Even Spacing стовпи збиваються в купу там, де кривизна вища.
На еліптичній дузі розкид кроку падає приблизно з 3× до 1.05×, на спіралі — з 5.5× до 1.25×.

## Нелипкі інструменти

Інструмент перебудовує сплайн **тільки** коли змінюється щось із його налаштувань — сам
інструмент, `Num Spline Points` або поля його структури опцій. Тому: крутите параметри —
форма оновлюється живо; тягнете точку мишею — правка лишається. Кнопка **Apply Point Layout**
розкладає точки заново, коли потрібен чистий старт. Збережені сцени візуально не змінюються:
точки лежать у рівні, а не перераховуються під час завантаження.
