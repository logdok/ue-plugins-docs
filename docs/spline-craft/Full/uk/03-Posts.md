# Стовпи (Posts)

*[🇬🇧 English](../en/03-Posts.md) | 🇺🇦 Українська*

Секція **POSTS** розміщує статичний меш у кожній активній точці сплайна: паркан, балясина,
колона, стійка. Один запис масиву `Posts` — це один «шар» стовпів уздовж усього сплайна;
записів може бути кілька (наприклад, стовп + окрема база).

## Стовп (`FSCPoint`)

| Параметр | Призначення |
|---|---|
| **Distance From Bottom** | висота над сплайном (см). |
| **Visible All** | вимикач усього запису. |
| **Main Static Mesh Configuration** | головна конфігурація меша (нижче). |
| **Detailed Visibility Configuration** | детальні правила видимості цього запису — див. [Правила видимості](07-Visibility-Rules.md). |
| **Knobs** (`Point Knobs`) | масив вузлів, змонтованих на стовпі — див. [Вузли](05-Knobs-And-Free-Knobs.md). |
| **Visible Knobs** | вимикач усіх вузлів цього стовпа. |

## Головна конфігурація меша (`FSCPointMeshConfig`)

| Параметр | Призначення |
|---|---|
| **Static Mesh** | меш стовпа. |
| **Visible** | показувати меш. |
| **Scale** | масштаб (`FVector`). |
| **Shift** | зсув (`FVector`, см): X — уздовж сплайна, Y — убік, Z — вгору. |
| **Rotation** | доданий поворот. |
| **Displayed Object** (`EShowKnobMode`) | `Mesh` — показати меш; `Actor` — заспавнити актор (видно лише у грі). Див. [Додаткові актори](12-Additional-Actors.md). |
| **Actor** (`FSCAdditionalActor`) | клас актора, коли обрано режим `Actor`. |
| **Ignore … Randomization Settings** | окремо вимкнути рандомізацію масштабу / зсуву / повороту. |
| **Randomization Settings** | розкид масштабу, зсуву та кутів — див. [Рандомізація](08-Randomization.md). |

**Боковий зсув (Shift.Y)** застосовується як паралельний контур (митра): зсунутий ряд стовпів
лишається строго паралельним сплайну навіть на поворотах, а не затягується в кут.

## Альтернативні меші (`Alternate Meshes`)

Підміняють головний меш за позицією точки: **First**, **Last**, **Odd**, **Even**. Спрацьовує,
якщо у відповідній конфігурації задано валідний меш (або клас актора) і ввімкнено `Visible`.
Вимикається прапорцем **Ignore Alternate Meshes**.

## Спеціальні меші (`Special Meshes`)

Список конфігурацій, кожна з набором **Visible At Index Ranges**: у точках із цими індексами
головний меш підміняється спеціальним. Має пріоритет над альтернативними та випадковими.
Вимикається прапорцем **Ignore Special Meshes**.

## Випадкові меші (`Random Meshes`)

Увімкніть **Use Random Meshes** і заповніть список **Random Meshes** — у кожній точці меш
вибирається випадково з-поміж валідних. Для відтворюваного результату задайте
[Random Seed](08-Randomization.md).

## Порядок вибору меша

Спеціальні → випадкові → альтернативні → головний. Перший, що спрацював, і використовується;
його `Shift` додається до `Shift` головної конфігурації.

## Видимість

- **Visible All**, **Visible All Knobs** — на рівні секції `POSTS`.
- **All Posts Visibility Configuration** — правила видимості для всіх стовпів одразу.
- Останню точку незамкненого сплайна показано лише за **Visible Last Point Elements** на акторі.

Повна логіка — у розділі [Правила видимості та проєми](07-Visibility-Rules.md).
