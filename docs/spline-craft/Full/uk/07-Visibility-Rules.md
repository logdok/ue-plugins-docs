# Правила видимості та проєми (Openings)

*[🇬🇧 English](../en/07-Visibility-Rules.md) | 🇺🇦 Українська*

Є два незалежні способи прибрати частину структури: **правила видимості за індексами**
(`FSCVisibleConfig`) і **проєми за відстанню** (`FSCOpenings`).

---

## Частина 1. Правила видимості (`FSCVisibleConfig`)

Керують тим, які екземпляри примітива відображаються — залежно від їхнього індексу
розміщення. Застосовуються на двох рівнях:

1. **Загальний рівень секції** — `All Posts / Sections / Tubes / Knobs Visibility Configuration`.
2. **Детальний рівень запису** — `Detailed Visibility Configuration` конкретного стовпа,
   секції, труби чи вузла.

Екземпляр видно, лише якщо він **пройшов обидва рівні**.

### Параметри

| Параметр | Дія |
|---|---|
| **Hide At Indexes** | приховати за переліком індексів. |
| **Hide In Index Ranges** | приховати за діапазонами індексів. |
| **Visible Every Multiple** | показувати, лише якщо індекс кратний значенню (0 — вимкнено). |
| **Hide Every Multiple** | протилежне: приховати, якщо індекс кратний значенню. |
| **Visible First** / **Visible Last** | показувати перший / останній екземпляр. |
| **Visible Only Extreme** | показувати лише перший та останній, решту приховати. |
| **Visible Odd** / **Visible Even** | показувати непарні / парні. |
| **Design Notes** | вільна нотатка. |

### Порядок застосування

1. Якщо індекс у **Hide At Indexes** або в **Hide In Index Ranges** — приховати.
2. Інакше, якщо задано **Visible Every Multiple** — показати тільки на кратних індексах.
3. Інакше, якщо задано **Hide Every Multiple** — приховати на кратних індексах.
4. Інакше застосувати правила крайніх і парності: перший → `Visible First`,
   останній → `Visible Last`, у середині → `Visible Only Extreme` ховає все,
   а без нього діє `Visible Odd` / `Visible Even`.

`Visible Every Multiple` і `Hide Every Multiple` взаємовиключні — увімкнення одного ховає
поле іншого.

---

## Частина 2. Проєми (Openings)

Секція **OPENINGS** вирізає в структурі прогалини — ворота, хвіртки, проходи —
**за відстанню вздовж сплайна в сантиметрах**, а не за арифметикою індексів.

### `FSCOpenings`

- **Use Openings** — головний вимикач усіх проємів нижче.
- **Openings** — список проємів.

### Проєм (`FSCOpening`)

| Параметр | Призначення |
|---|---|
| **Enabled** | увімкнути цей проєм. |
| **Start** | відстань від початку сплайна до початку проєму (см). |
| **Width** | ширина проєму вздовж сплайна (см). |
| **Affect Posts / Knobs / Sections / Tubes** | яких елементів торкається проєм. |
| **Design Notes** | вільна нотатка. |

### Як це працює

- **Точки** (Posts, Knobs) прибираються, якщо потрапляють **строго всередину** проєму.
- **Секції та труби** прибираються, якщо **перетинаються** з проємом.
- Елемент рівно на межі **лишається** — тому стовпи по краях воріт зберігаються.
- Разом з елементом ховаються і його вузли, в обох режимах — Line і Curve.
- Проєми **не ріжуть геометрію**: ховаються цілі елементи. Для рівного краю воріт ставте
  точки сплайна по їхніх межах.
- **Free Knobs** і **Polygons** проємами не зачіпаються.

### Підсвітка в редакторі

Кожен увімкнений проєм малюється у в'юпортi оранжевою рамкою — видно, де він починається
й закінчується, без підбору цифр на око. Вимикається прапорцем **Show Openings In Viewport**
на акторі. У грі рамка не малюється ніколи.

За замовчуванням список проємів порожній — наявні сцени не змінюються.
