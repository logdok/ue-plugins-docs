# Полігони (Polygons)

*[🇬🇧 English](../en/06-Polygons.md) | 🇺🇦 Українська*

Секція **POLYGONS** генерує суцільну заповнену форму процедурним мешем
(`UProceduralMeshComponent`): підлогу, стелю, платформу, кришку двору, водну гладь усередині
огорожі. Контур форми — це всі точки сплайна.

## Полігон (`FSCPolygon`)

| Параметр | Призначення |
|---|---|
| **Visible** | будувати полігон. |
| **Distance From Bottom** | висота нижньої грані над сплайном (см). |
| **Height** | товщина призми (см). |
| **Shift** (`FSCShift`) | зсув Horizontal / Vertical (см). |
| **Yaw Rotation (Z)** | поворот полігона навколо вертикалі (градуси). |
| **Follow Curve** | брати вигнутий контур сплайна замість прямої хорди між точками. Не має видимого ефекту там, де точки прямі (тип `Linear`). |
| **Curve Resolution** | крок вибірки вздовж кривої (см), коли ввімкнено **Follow Curve**. Менше — гладше й важче. |
| **Material** | матеріал. **Без матеріалу полігон не будується.** |

`FSCPolygons` має спільний вимикач **Visible All**.

## Форма контуру

- Крышки (верх і низ) триангулюються **відсіканням вух** (ear clipping): підтримується
  будь-який несамоперетинний контур — опуклий, вогнутий (L-подібний, зіркоподібний,
  гребінка), з колінеарними точками, які створюють інструменти розкладки.
- Самоперетинний контур відкочується на просту тріангуляцію віялом (коректну лише для
  опуклих форм).
- Напрямок обходу визначається за знаком площі, тому полігон, намальований за годинниковою
  стрілкою, не вивертається навиворіт.
- Боковий зсув (**Shift.Horizontal**) застосовується як паралельний контур (митра).

## Колізія

Колізію полігонів вмикає прапорець **Polygons Create Collision** у секції **Collision**
(потрібен увімкнений **Override Collision**). Для суто декоративних форм її можна вимкнути.
Решта налаштувань колізії застосовується до полігонів так само, як до інших компонентів —
див. [розділ 10](10-Runtime-And-Blueprint-API.md).

## Продуктивність

Кожен полігон — це один процедурний меш-компонент; їхню кількість показує секція **Stats**
у Details. Полігони входять у [Merge to Static Mesh](11-Merge-To-Static-Mesh.md): перед
злиттям кожен запікається у тимчасовий статичний меш.
