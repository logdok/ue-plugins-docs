# Додаткові актори

*[🇬🇧 English](../en/12-Additional-Actors.md) | 🇺🇦 Українська*

Будь-який вузол може відображати не меш, а **актор** — коли **Displayed Object = `Actor`**.
Так у структуру потрапляють ліхтарі з логікою, прапори з фізикою, тригери, партикли — усе,
що є повноцінним актором. Актори з'являються **лише у грі**; у режимі редагування вони не
видимі.

## Параметри (`FSCAdditionalActor`)

| Параметр | Призначення |
|---|---|
| **Actor Class** | клас актора, який спавнити (`TSubclassOf<AActor>`). |
| **Scale** | додатковий масштаб (`FVector`), множиться поверх трансформації спавну. |
| **Spawn Transform** | обчислена трансформація спавну — лише для читання. |

Значення **Shift** і **Rotation** беруться з налаштувань самого вузла, до якого прикріплено
актор.

## Спавн і життєвий цикл

- Актори спавняться у **`BeginPlay`** (метод `SpawnAdditionalActorsIfNeeded`), після
  побудови геометрії.
- Кожен заспавнений актор **прикріплюється** до актора SplineCraft і отримує тег з іменем
  актора-власника (`GetFName()`).
- При перебудові (`CoreClean`) усі раніше заспавнені додаткові актори знищуються за цим тегом
  і спавняться заново.
- У runtime повторний спавн відбувається всередині `UpdateAfterChangeAnyProperty()`
  (за умови **Mobility ≠ Static**).

## Де можна використати режим `Actor`

- **Posts / Knobs** — `Main Static Mesh Configuration → Displayed Object = Actor`.
- **Вузли на секціях і трубах** (`FSCElementKnob`) — `Displayed Object = Actor`.
- **Free Knobs** — так само.
