# Злиття у статичний меш

*[🇬🇧 English](../en/11-Merge-To-Static-Mesh.md) | 🇺🇦 Українська*

Функція **Merge to Static Mesh** доступна лише в редакторі. Вона запікає всю згенеровану
геометрію актора — стовпи, секції, труби, вузли й полігони — в один ассет `StaticMesh`
і ставить на сцену `StaticMeshActor` з ним.

Це **рекомендований шлях для великих статичних структур** — довгих огорож, парканів,
доріг, трас, стін, — коли параметри вже не потрібно змінювати. Замість сотень
компонентів отримуєте один меш, який рушій обробляє як звичайну статичну геометрію.

## Робочий процес

1. **Повністю налаштуйте структуру** — форму сплайна, стовпи, секції, вузли, полігони.
   Після злиття параметри вже не редагуються (див. «Обмеження»).
2. **Задайте Merge Settings** — це стандартні `FMeshMergingSettings` рушія: об'єднання
   та спрощення матеріалів, генерація лайтмап-розгортки тощо. Для більшості випадків
   вистачає значень за замовчуванням.
3. **Натисніть `Merge to Static Mesh`.** З'явиться діалог підтвердження. Новий ассет
   `StaticMesh` створюється в `/Game/Meshes/`, на сцену додається `StaticMeshActor`.
4. За потреби увімкніть **Replace Spline Actor** *перед* злиттям — тоді актор SplineCraft
   буде видалено, а на його місці залишиться лише запечений меш.
5. **Увімкніть Nanite** на отриманому `StaticMesh` (у його налаштуваннях). Nanite сам
   бере на себе відсікання й деталізацію на будь-якій відстані — окремі LOD робити не
   треба. Для великої огорожі це найкращий результат за продуктивністю.

## Параметри

- **Merge Settings** (`FMeshMergingSettings`) — спрощення матеріалів, лайтмапи, налаштування
  злиття.
- **Replace Spline Actor** — видалити актор сплайна після злиття й лишити тільки меш.

Обидва параметри доступні лише для екземпляра актора на сцені (не для Blueprint-класу).

## Що потрапляє у результат

- Стовпи, секції, труби та вузли — з обох режимів, Line і Curve.
- **Полігони** — процедурний меш полігонів перед злиттям запікається у тимчасовий
  статичний меш і теж входить у результат.
- Маркери проємів у в'юпортi — суто редакторна підсвітка, у злиття не потрапляють.

## Обмеження

- **Незворотно.** Запечений меш не пов'язаний з актором. Щоб змінити огорожу, треба
  повернути актор SplineCraft (якщо був увімкнений Replace Spline Actor — з історії
  або заново) і виконати злиття ще раз.
- **Одна велика сітка.** Оклюзія стає грубішою, ніж коли кожна секція — окремий
  компонент: рушій ховає меш цілком або не ховає зовсім. Для дуже довгих структур
  варто різати на кілька акторів і мержити кожен окремо.
- Колізія та лайтмапи запеченого меша залежать від Merge Settings і налаштувань самого
  `StaticMesh` — перевірте їх після злиття.
