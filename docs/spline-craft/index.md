# SplineCraft

<!-- last-synced:start -->
<!-- last-synced:end -->

Rapid procedural structures along a spline for **Unreal Engine 5.8** — fences, railings,
balustrades, colonnades, arcades, barricades, bridges, roads. Everything is configured on a
single `ASplineCraftActor` in the **Details** panel, and the geometry rebuilds automatically
on every change. From Blueprint or C++.

## Note on the name

The plugin was previously published as **SplineCraft PRO**. It is now simply **SplineCraft**.
The rename does not affect backward compatibility — the module name, content mount point, class
paths and property layout are unchanged, so existing levels and Blueprints keep working. See
the [Release Notes](Full/en/Release-Notes.md).
