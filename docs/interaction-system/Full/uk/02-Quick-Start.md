# 02 — Швидкий старт

*[🇬🇧 English](../en/02-Quick-Start.md) | 🇺🇦 Українська*

Один повний приклад: desktop-персонаж бере предмет, кидає його й відчиняє двері. Після кожного кроку ви бачите результат. Покрокові вправи з поясненнями — у [14 — Покрокові уроки](14-Tutorials.md).

## Кроки

1. Увімкніть **Edit → Plugins → InteractionSystem** у проєкті UE 5.8 і перезапустіть редактор.

   **Результат:** у **Components → Add** з'явився `InteractorComponent`.

2. У Blueprint персонажа увімкніть **Replicates** і додайте `InteractorComponent`, прикріпивши його до камери. Залиште `Use Pawn Viewpoint` увімкненим: джерело братиме поточну точку огляду контролера.

   **Результат:** у вікні компонентів джерело стоїть під камерою.

3. Створіть Blueprint від `InteractionMasterItem`. Призначте `Mesh Component` статичний mesh із простою колізією, яка на каналі `Visibility` відповідає **Block**. Розмістіть предмет перед камерою на відстані до 300 см.

   **Результат:** у грі поруч із предметом з'являється маленька точка, а при наведенні — `E`.

4. У своєму input mapping прив'яжіть одну дію до `Request Grab`, другу — до `Request Release`. Для відпускання без кидка передайте нульові вектори; для кидка — швидкість у см/с і кутову швидкість у градусах/с.

   **Результат:** після натискання першої дії предмет опиняється перед камерою; друга дія відпускає або кидає його.

5. Для дверей або кнопки реалізуйте `Interaction` і викликайте `Request Interaction` замість `Request Grab`. Готовий фізичний актор також має серверну подію `On Interacted`. Покроковий приклад дверей, які бачать усі гравці, — [урок 2](14-Tutorials.md#урок-2-двері-які-відчиняються-для-всіх-гравців).

   **Результат:** двері реагують на натискання.

`E` — лише початковий текст підказки. Змініть `Interaction Prompt` або призначте текстуру `Focus Icon → Sprite` відповідно до ваших клавіш. Плагін сам не додає клавіш.

> **Простими словами.** Наведення — це лише «показати пальцем». Сам предмет потрапляє в руку, коли сервер погодився: в одиночній грі це миттєво, у мережевій — через час обміну з сервером.

## Якщо щось не працює

Введіть у консолі гри `InteractionOverlay`. Праворуч з'явиться панель: чи бачить джерело предмет (**Focus**), у якому стані рука (**State**) і що відповів сервер (**Last answer**). Розшифровка — у [15 — Інструменти налагодження](15-Debug-Tools.md).

## Готовий приклад

У Content Browser увімкніть **Show Plugin Content** і відкрийте `/InteractionSystem/Demo/InteractionLab/Maps/InteractionLab`. Рух — WASD, огляд — миша, `E` — захоплення або двері, `F` — кидок. Персонаж демо створює своє введення Enhanced Input у коді й не змінює налаштувань вашого проєкту.

У C++-модулі додайте `InteractionSystem` у залежності; для готових предметів — також `InteractionSystemWorld` ([12](12-Cpp-Integration.md#залежності-модуля)).
